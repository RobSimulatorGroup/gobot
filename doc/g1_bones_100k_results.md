# G1 BONES：100k 训练与评测结果

记录日期：2026-11-06。用户在 8×RTX 4090 上完成从头训练：100000 控制步、39984 次学习更新、
3276800000 条环境 transition，日志主循环耗时约 10 小时 50 分钟。
训练回报最终为 0.81809；以下是另外运行的完整片段评测，不能与训练回报混用。

## 协议与身份

- 权重 SHA256：`89de8a3bd3774b4c407bc92063d5447c76efb49c54bc8a930f81cfed2605e279`。
- 软件：Torch 2.11.0+cu128、MuJoCo/MuJoCo Warp 3.17.0、Warp 1.17.0。
- 训练配置：[reproduced_bones_nj500.json](../examples/g1/train/reproduced_bones_nj500.json)。
  每卡 4096 环境、WM/policy batch 2048、H=32；100k 停止与 320k LR 调度分别保留。
- 训练物理容量 35/500；评测容量 128/500，明确不同于发布的 35/250 配方。
- 评测从首帧开始，使用 dense FP32 参考动作、确定性 actor，关闭观测/动作/reset 噪声及 DR，
  足部摩擦 1.0，取消训练的 10 秒 episode 截断。
- 额外 Warp deterministic reductions 关闭，与固定参考实现实际代码一致。
  参考 benchmark 的文字说明称 deterministic physics，但其 mjlab 配置没有开启这些归约。
- 数据由 142220 条原始 CSV 独立筛选：历史训练名称过滤后 130137 条，物理可行性再剔除 194 条。
  原始训练库字节未公开，当前库是可追溯重建；发布评测名单只用于筛选后的核对。

130 个分片完整覆盖所有动作，每个 NPZ 均核对哈希；每次物理步后检查溢出，
同时检查非有限状态、缺失/重复片段及提前结束。最终 v3 报告没有容量溢出或异常。
初期额外确定性归约诊断的工作区超限/停止记录保留在 v1/v2，未计入最终结果。

复测 3072 条动作，失败标签一致；三个分片的平均 return 差为 0.0000288、0.0000475、0.0001907。
最大单片段差为 0.13016，一条失败片段的终止步数改变。不能宣称逐位可重复。

## 与发布成绩的关系

| 集合 | 参考发布回报 / 失败数 | Gobot 回报 / 失败数 |
|---|---:|---:|
| 全量 | 0.93019 / 495 | 0.93556 / 429 |
| 过滤子集 | 0.93147 / 145 | 0.93691 / 90 |

本次达到参考 BONES 发布指标水平，但不构成同条件胜出：参考用 4 个训练 rank，本次用 8 个，
相同每卡配置和控制步数下全局采样量翻倍，学习率也随 rank 数缩放；软件和容量也不同。
当前只有一个 seed，评测动作属于训练库，尚未完成同栈、同预算、多 seed 配对复现。

按名字关键词统计，`flip` 54/54、`handstand` 160/160、`cartwheel` 99/120、`safety_roll` 46/46 失败。
`walk` 3/22482、`run` 1/734、`jump` 48/13405 失败。这是可重叠的名字分组，不能等同于人工动作分类。
