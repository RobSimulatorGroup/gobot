# Allegro Hand V3 asset source

The files in this directory are copied from:

- Repository: `google-deepmind/mujoco_menagerie`
- Directory: `wonik_allegro`
- Commit: `da76818e269b82289eba39808e2fb91d679d6994`
- Upstream URL: https://github.com/google-deepmind/mujoco_menagerie/tree/main/wonik_allegro

The model contains the left- and right-handed Allegro Hand V3 MJCF
descriptions and their STL meshes. Gobot loads the visual meshes and maps the
three fingers and thumb onto two low-cost synergy drives per hand. The original
16-DOF MJCF descriptions are preserved here as the authoritative source.
